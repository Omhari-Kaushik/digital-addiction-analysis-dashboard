# Digital Addiction & Student Life Impact Analysis

## Overview
This project analyzes the impact of digital addiction on students' academic performance and lifestyle using data analysis and visualization techniques.

## Tools Used
- Python (Data Cleaning)
- Microsoft Excel (Dashboard & Visualization)

## Key Features
- Data cleaning and preprocessing
- Interactive dashboard using Excel
- Visualization of trends and correlations

## Key Insights
- Higher screen time showed a negative impact on productivity
- Patterns identified between digital usage and lifestyle habits
